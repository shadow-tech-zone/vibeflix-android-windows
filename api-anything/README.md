# API Anything site adapters

The [Play4u](play4u/README.md) adapter is a read-only, public-catalog integration with a canonical spec shared by VibeFlix's Vercel function and API Anything's CLI/MCP installer. Its interface is `browseTitles` (search, filters, pagination) and `getTitle` (movie or series metadata). Vercel test instructions and remaining live-verification caveats are in the Play4u README.
